## 6. Coverage and review discipline: 100% after *each* completed piece

Explicit coverage include patterns must cover every relevant first-party V3 module, including security guards, failure branches and model evaluator. Do not exclude hard-to-test guards, use `pragma: no cover` to game the result, omit modules not imported by tests or pad with meaningless tests. Test files, generated fixtures and vendored external packages are not first-party production code and are excluded transparently. Record denominator, missed lines/branches and artifact hash after each stage.

Run, at minimum, with the exact approved pinned tooling equivalent of:

`pytest -q --strict-markers --strict-config --cov=v3.offline --cov-branch --cov-report=term-missing --cov-report=xml --cov-fail-under=100`
